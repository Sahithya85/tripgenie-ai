How TripGenie works

A form-based pipeline — the LLM is a function, not a chat window.

📝
1. Validate

JavaScript checks dates, budget, traveler count and required fields.

🧩
2. Prompt

Inputs are turned into a structured prompt that demands a strict JSON schema.

🤖
3. LLM call

The browser sends your inputs to our Node.js server, which calls the LLM API using a secret key stored in .env.

🗺️
4. Render

The JSON is parsed and shown as day cards, a budget chart and tips.
